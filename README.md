# 技术学习笔记

**Java 后端 · 数据库与中间件 · 计算机基础 · AI 与大模型**

这里整理了我在学习计算机基础、Java 后端和大模型相关技术时积累的笔记。目前收录 **45 篇**，会随着学习和实践继续更新。

这些记录既有对教材、技术文档和其他学习资料的梳理，也有我在学习过程中遇到的问题、对底层机制的追问、代码示例和错误复盘。我希望它不只是一个知识点清单，而是一份能够持续回看、修正和扩展的个人技术知识库。

### 部分学习主题

- **JVM：** 运行时数据区域、垃圾回收、类加载、字节码执行与性能分析。
- **Java 并发：** Java 内存模型、`synchronized`、CAS、无锁编程、Monitor 和并发工具。
- **网络与通信：** TCP 连接、拥塞控制、流量控制、HTTP，以及 Netty 的事件驱动模型。
- **数据库：** MySQL 索引及查询优化、事务相关概念与 Redis。
- **大模型与 Agent：** Attention 与 Q/K/V、LoRA 等微调方法、量化、RLHF，以及 Agent Coding 中的 Skills 等机制。
- **算法：** LeetCode Hot 100 的解题思路、边界条件、代码实现和错误总结。

其中，**「Java 底层机制与原理深挖」**主要记录阅读技术资料后，对暂时没有理解透彻的实现细节继续查阅、追问和整理的过程。

## 我的整理方式

在学习中，我通常会先梳理一个技术点的基本概念，再尝试回答“为什么要这样设计”“内部如何实现”“有哪些限制或边界情况”。对于代码和算法，会尽量记录关键执行过程，以及自己曾经出现的错误和修正思路。

笔记会随着理解加深不断修改，因此部分内容可能存在遗漏、理解偏差或版本适用范围上的限制；也欢迎通过 Issues 交流和指正。

## 本地预览

如果希望在本地生成相同的网站，可以在安装 Python 后运行：

```powershell
pip install -r requirements.txt
python build.py
```

或者在 Windows 上运行 `build.bat`，然后打开 `site/index.html`。新增笔记可按分类放入 `incoming/`：思源导出的 `.md.zip` 可直接使用，幕布导出的 `.html` 也可导入；其中远程图片能否显示取决于是否成功缓存。
