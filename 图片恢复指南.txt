幕布 HTML 图片与思源 ZIP 图片的区别
=================================

- 思源导出的 ZIP 本身含 assets 图片，可以直接内嵌到网站 HTML。
- 幕布导出的 HTML/OPML 通常只含图片网址（没有图片文件），需要联网保存。

怎么做：
1. 把原始 .html 放进 incoming 下对应的文件夹。
2. 双击 build.bat；程序自动尝试下载所有幕布图片。
3. 如果构建窗口显示「有 N 张幕布图片未保存成功」：
   双击博客根目录新生成的「恢复幕布图片.html」。
4. 在浏览器页面点击「尝试批量下载并打包图片」。
5. 如果成功下载 mubu-images.zip，把这个 ZIP 放进 cached_images 文件夹，
   不需要解压，重新双击 build.bat。
6. 检查网页中的图片。若浏览器也无法批量下载，可点击失败项的
   「在浏览器打开原图」逐张查看；若能打开，另存到 cached_images 并按
   网页列出的哈希文件名保存。不建议修改原始 HTML。

重要限制：如果幕布服务器拒绝 Python 和浏览器读取，导出的 HTML
本身又没有图片数据，任何转换程序都不能无中生有恢复原图。

不要把「恢复幕布图片.html」发布到公网；它放在项目根目录，不在 site 内。
